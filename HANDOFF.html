1. What Was Delivered

A fully designed and built Astro website for Second Chances — a Kenya-rooted care-leaver support organisation. The project covers visual identity integration, information architecture, a full 11-page site, a CMS integration, serverless form relay, and deployment configuration for Cloudflare Pages.

Environment Variables Required

Action required

These variables must be set in Cloudflare Pages > Settings > Environment Variables before the first production deploy. None are committed to the repository.

VariableWhere to get it
POSTMARK_TOKENPostmark account > API Tokens
RELAY_TOThe inbox address forms should deliver to (e.g. hello@secondchances.co.ke)
TURNSTILE_SECRETCloudflare Dashboard > Turnstile > your widget
PUBLIC_TURNSTILE_SITEKEYSame Turnstile widget (the public key)
PUBLIC_PAYSTACK_KEYPaystack Dashboard > Settings > API Keys > Public Key
KEYSTATIC_GITHUB_CLIENT_IDGitHub OAuth App (for Keystatic CMS production auth)
KEYSTATIC_GITHUB_CLIENT_SECRETSame GitHub OAuth App
KEYSTATIC_SECRETAny 32+ char random string (session signing)

Keystatic CMS — Production Mode

During development Keystatic uses kind: local (no auth required). For production switch to kind: github in app/keystatic.config.ts and register a GitHub OAuth App pointing to https://secondchances.co.ke/api/keystatic/github/oauth/callback.

DNS

Point secondchances.co.ke (CNAME or A) to the Cloudflare Pages domain. Add 301 redirects for any other variants (.com, .org) in the Cloudflare Pages redirect rules or _redirects file.

4. Remaining Items Before Launch

Must-Do (P1 — Launch Blockers)

  • Set all environment variables in Cloudflare Pages (see Section 3)
  • Replace Unsplash placeholder images with commissioned/licensed photography
  • Update placeholder contact numbers in app/src/config.ts (currently +254 700 000 000)
  • Self-host Oswald (or license Tungsten) — remove Google Fonts CDN call for performance + privacy
  • Write and publish Privacy Notice (Kenya Data Protection Act 2019 — ODPC registration)
  • Write and publish Terms of Use
  • Wire Paystack: replace PUBLIC_PAYSTACK_KEY placeholder with live key; test M-Pesa + card flows
  • Configure and test Postmark relay for all three form endpoints (get-help / contact / refer)
  • Create Cloudflare Turnstile widget; add site key + secret to env vars
  • Final content review by Peter's team — team bios, pillar descriptions, impact figures
  • Add real annual report PDF URL to app/src/content/reports/annual-report-2024.md
  • Verify fund allocation percentages (app/src/config.ts — currently illustrative)
  • DNS cutover to secondchances.co.ke; test all routes 200; check redirects

Phase 2 (Post-Launch Enhancements)

  • Kiswahili translation (Astro i18n routing — scaffold already in place)
  • Native M-Pesa STK Push via Safaricom Daraja (smoother in-page donation flow)
  • Resources & Guides page (currently 404 — linked in footer)
  • Switch analytics to Plausible if Cloudflare Web Analytics proves insufficient
  • Keystatic GitHub mode (CMS in production) — requires GitHub OAuth App setup

Do not rely on the root SVG file as-is for print or third-party use — it needs repair before sending to a printer or designer.

7. Security & Privacy Notes

  • Forms use server-side relay — no data stored in a database (data minimisation)
  • No Google Analytics — cookieless, privacy-first analytics only
  • No reCAPTCHA — Cloudflare Turnstile (no cross-site tracking)
  • Shared-device safety on Get Help page (neutral tab title, quick Exit button)
  • No identifying photographs of beneficiaries — duotone treatment policy
  • Privacy Notice required before launch (Kenya Data Protection Act 2019)
  • ODPC registration as data controller — Peter's team to initiate
  • TLS enforced via Cloudflare (automatic)
